# Travessia Essencial

Página de divulgação da **Travessia Essencial — O caminho de volta para mim**, criada em HTML, CSS e JavaScript simples para publicação no GitHub Pages.

## Conteúdo atual

A página apresenta a Travessia Essencial como um grupo fechado de aprofundamento em autoconhecimento com base na metodologia Pathwork®, conduzido por **Nazaré Pereira — Helper Pathwork®**.

Informações principais da jornada:

- **Período:** agosto a dezembro de 2026
- **Formato:** online pelo Zoom
- **Encontros:** semanais, às terças-feiras
- **Duração:** 1h30 por encontro
- **Dezembro:** somente 1 encontro de fechamento do ciclo
- **Investimento:** R$ 130,00 por mês
- **Formato do grupo:** grupo fechado de aprofundamento

A proposta trabalha quatro pilares: direção interior, verdade interna, criança ferida e responsabilidade interior.

## Arquivos

- `index.html`: estrutura da página, conteúdo principal, chamada única de WhatsApp, seções da jornada e uso da logo do Despertar Essencial.
- `styles.css`: identidade visual em tons de verde profundo, dourado e bege/solar, responsividade, cards e acabamento visual.
- `script.js`: configuração do botão de inscrição pelo WhatsApp com mensagem automática.
- `assets/despertar-essencial-logo.svg`: logo oficial do Despertar Essencial usada no topo e no rodapé da página.

## Publicação no GitHub Pages

1. Envie estes arquivos para um repositório no GitHub.
2. Acesse **Settings** no repositório.
3. Entre em **Pages**.
4. Em **Build and deployment**, selecione **Deploy from a branch**.
5. Escolha a branch principal, normalmente `main`, e a pasta `/root`.
6. Clique em **Save** e aguarde o GitHub gerar o link público da página.
