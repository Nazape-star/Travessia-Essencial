# Travessia Essencial

Página de divulgação da **Travessia Essencial — O Chamado de Volta para Mim**, criada em HTML, CSS e JavaScript simples para publicação no GitHub Pages.

## Arquivos

- `index.html`: estrutura da página e conteúdo principal.
- `styles.css`: estilos visuais, responsividade e acabamento da página.
- `script.js`: configuração do botão de inscrição pelo WhatsApp.

## Como publicar no GitHub Pages

1. Envie estes arquivos para um repositório no GitHub.
2. Acesse **Settings** no repositório.
3. Entre em **Pages**.
4. Em **Build and deployment**, selecione **Deploy from a branch**.
5. Escolha a branch principal, normalmente `main`, e a pasta `/root`.
6. Clique em **Save** e aguarde o GitHub gerar o link público da página.
